# Renewables GIS portfolio

Course exercises from the “GIS and Geodata Expert” continuing education program at GIS-Akademie GmbH (Berlin, 2026), reworked as portfolio pieces on renewable-energy siting.

Each exercise follows the same structure: **question → data and source → method → result → analytical limits**. The last part matters most. A course exercise is not industry experience; what it can show is an understanding of the sector's logic and vocabulary, and of where the teaching parameters part ways with real projects.

## Exercises

| # | Exercise | Question | Tools |
|---|---|---|---|
| 01 | [Cable route](01-cable-route/) | Least-cost grid connection for a wind farm, with three connection points compared | ArcGIS Pro, Spatial Analyst, arcpy |
| 02 | Wind farm planning | Which of two wind farm sites has less visual impact on recreation areas? | *planned* |
| 03 | Solar radiation | Solar potential on roofs | *planned* |
| 04 | Hidden areas | Sites for a solar park hidden from critical infrastructure | *planned* |
